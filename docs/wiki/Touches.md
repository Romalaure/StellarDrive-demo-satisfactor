# Touches et réglages

## Touches
| Touche | À quoi ça sert |
|---|---|
| Regarder une machine | Voir son état, sa recette, sa progression, son énergie et son contenu |
| `N` | Passer à la recette suivante (Maj+N : la précédente), ou changer le mode d'un quai |
| `K` | Scanner les rochers autour de vous pendant 8 secondes |
| `F7` | Ouvrir le tableau de bord de l'usine |
| `G` | Ouvrir le guide du jeu, où se trouve ce wiki |

## Réglages
Ils se trouvent dans `UserData/MelonPreferences.cfg`, section `[StellarIndustries]` :

| Réglage | Effet |
|---|---|
| `Language` | langue du mod : `auto` (suit le jeu), `fr` ou `en` |
| `Enabled` | `false` met toutes les machines en pause |
| `ProductionSpeed` | accélère ou ralentit toutes les machines (0,1 à 10) |
| `PowerFactor` | ajuste leur consommation électrique (0 à 10) |
| `RequirePower` | `false` : les machines tournent sans câble |
| `ResearchUnlocks` | `false` : toutes les machines disponibles tout de suite |
| `RecipeKey`, `ScanKey`, `OverviewKey` | changer les touches |
| `MachineVolume` | volume du bruit des machines |
