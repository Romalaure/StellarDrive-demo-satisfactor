# Touches et réglages

## Touches
| Touche | Effet |
|---|---|
| Viser une machine | Panneau d'état : état, recette, progression, énergie, contenu |
| `N` | Recette suivante de la machine visée (Maj+N : précédente) ; mode d'un quai |
| `K` | Scanner de gisements : rochers autour de vous pendant 8 s |
| `F7` | Tableau de bord : machines par état, énergie, problèmes |
| `G` | Guide du jeu, avec ce wiki |

## Réglages
Dans `UserData/MelonPreferences.cfg`, section `[StellarIndustries]` :

| Réglage | Effet |
|---|---|
| `Enabled` | `false` : plus aucune production |
| `ProductionSpeed` | vitesse de toutes les machines (0,1 à 10) |
| `PowerFactor` | consommation électrique (0 à 10) |
| `RequirePower` | `false` : les machines tournent sans câble |
| `ResearchUnlocks` | `false` : toutes les machines disponibles sans recherche |
| `RecipeKey`, `ScanKey`, `OverviewKey` | changer les touches |
| `MachineVolume` | volume du bruit des machines |
