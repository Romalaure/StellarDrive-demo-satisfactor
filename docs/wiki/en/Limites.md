# Limits

A few things the mod does not do, and why.

- **10 slots per machine**: the machines use the game's own storage, which has 10.
- **No fluids** (oil, water in pipes…): the game doesn't let mods add new kinds of tanks. That's why the [Refinery](Machine-7612) works with biomass rather than oil.
- **No trains, trucks or drones**: StellarDrive has no reliable autopilot. For transport, a piloted cargo ship and two [transfer docks](Machine-7609) do the job nicely.
- **A cycle in progress restarts** when you reload your game. No item is ever lost, though.
- **The extractor** only sees rocks the game has loaded, that is, near a player.
- **In multiplayer**, everyone needs the mod, and the host runs the machines. Playing together hasn't really been tested yet, so please report any trouble.
